## 1. 学習目標

**今日の主な目標：** Vue.jsを使い、メモの登録・一覧表示・編集・削除を行う画面を、データと画面の関係を考えながら自分で設計・実装する。

**理解を確かめる方法：** 作成・選択・保存・削除の各操作で、どのデータが変わり、画面に何が表示されるかを自分の言葉で説明できること。特に、新規保存と更新保存の違い、保存済みメモと編集中の入力を分ける理由を説明できること。

自分の欲しいメモ帳を実装するという目的を残し、出来上がった動作と設計の一致は、第2章の完了条件と第5章の検証結果で確認する。

## 2. 要件と対象範囲

### 目的と対象

自分が楽にメモをし、管理しやすくするためのアプリ。利用者は自分とし、ローカルのブラウザで使用する。

### 今回行うこと・行わないこと

| 区分 | 内容 |
|---|---|
| 必須機能・実験 | メモの登録、登録したメモの一覧表示、メモの選択、タイトル・本文の編集、メモの削除 |
| 対象外 | 文字のスタイル変更、DB・ファイル・ブラウザストレージへの永続保存、再読み込み・タブを閉じた後の復元、タブ間のデータ共有、未保存の変更を破棄する際の確認ダイアログ、削除の確認ダイアログ、取り消し・Undo機能 |
| 前提・制約 | JavaScript・Vue.jsを使用する。ローカル実行とし、Vue.jsアプリの開発サーバーをDockerコンテナで起動する。メモは表示中のページのメモリだけに保持し、外部公開は行わない |

ここでいう「保存」は、編集欄の内容を、ページ内で保持するメモ一覧へ確定する操作を指す。永続保存ではない。アプリ起動時はメモ0件から開始し、再読み込み後やタブを閉じて再度開いたときの復元は行わない。
